# 📦 서식 내보내기·가져오기(전체 백업)와 AI 맞춤 서식 생성 (HELP-14)

온리비 어서의 모든 서식 프로필은 표준 JSON 스키마로 관리됩니다. 서식 관리 센터(`StyleManagerModal`)의 **4-Tab 워크스페이스 허브**를 통해 서식을 파일이나 클립보드로 내보내고 가져오거나, 내장/외부 AI로 전문가급 맞춤 서식을 10초 만에 생성할 수 있습니다.

---

## 1. 서식 내보내기 & 내 서식 전체 백업 (`📤 가져오기 & 내보내기 허브`)

내보낼 때는 항상 `normalizeCssProfile` 정규화를 거쳐 15대 카테고리 규칙(`rules`)과 모든 확장 구조체(`pageStyle`, `tableStructure`, `bulletStructure`, `checkboxStructure`, `hrStructure`, `mediaCaptionStructure`, `headingNumbering`, `layout`, `customCss`)가 누락 없이 100% 보존됩니다.

1. **개별 서식 파일 내보내기 (`.json`)**:
   - 좌측 사이드바 서식 항목의 **`[파일 내보내기]`** 아이콘 또는 본문 **`[선택 서식 파일 저장 (.json)]`** 카드를 클릭하면 `{서식이름}_theme.json` 파일로 다운로드됩니다.
2. **클립보드로 JSON 즉시 복사**:
   - 사이드바의 **`[JSON 복사]`** 아이콘, **`[클립보드로 JSON 복사]`** 카드, 또는 **`[{} 서식 JSON 코드 보기]`** 탭의 **`[전체 JSON 복사]`** 버튼을 눌러 서식 JSON 원문을 클립보드에 복사합니다.
3. **내 서식 전체 일괄 백업 (`Onrivi_내서식_백업_YYYYMMDD.json`)**:
   - 좌측 사이드바 상단의 **`전체 백업`** 버튼 또는 본문 **`[내 서식 전체 백업 (N개)]`** 카드를 클릭하면 내가 만든 모든 사용자 서식이 하나의 다중 배열 JSON 파일로 일괄 저장됩니다.

---

## 2. 외부 서식 가져오기 및 일괄 복원 (3가지 방식)

단일 서식 파일(`{ ... }`)뿐만 아니라 **전체 백업 배열 파일(`[ { ... }, ... ]`)**도 자동으로 인식하여 한 번에 등록하며, 일부 속성이 생략된 AI 생성 JSON도 `Onrivi 기본서식` 기준(제목 감소폭 `3pt`, 표준 여백 등)으로 100% 자동 보완합니다.

1. **마우스 드래그 앤 드롭 (Drag & Drop)**:
   - **`[파일로 불러오기 (.json)]`** 영역에 `.json` 서식 파일이나 전체 백업 파일을 끌어다 놓으면 즉시 등록됩니다.
2. **내 PC에서 파일 선택**:
   - **`[내 PC에서 파일 선택 (.json)]`** 버튼을 클릭해 로컬에 저장된 `.json` 파일을 불러옵니다. (좌측 서식 편집기의 외부 서식 가져오기 모달에서도 동일하게 단일/다중 백업 파일을 지원합니다.)
3. **클립보드 JSON 바로 불러오기 & 텍스트 붙여넣기**:
   - **`[클립보드 JSON 바로 불러오기]`** 버튼을 누르면 복사해 둔 JSON을 붙여넣기 과정 없이 원클릭으로 즉시 파싱·등록합니다.
   - **`[JSON 텍스트 붙여넣기]`** 탭에 텍스트를 붙여넣으면 하단에 **실시간 JSON 유효성 사전 검증 배지(`유효한 서식 N개 감지됨`)**가 표시되며, 마크다운 코드블록(```` ```json ````)이 섞여 있어도 자동으로 정제하여 인식합니다.

---

## 3. 내장 AI 프롬프트 서식 생성기 (`✨ AI 프롬프트 서식 생성기`)

환경설정에 Gemini API 키가 등록되어 있다면 에디터 안에서 자연어 지시만으로 15대 카테고리가 완비된 서식을 즉시 생성합니다.

1. **6대 국가·기업·출판 표준 프리셋 칩 원클릭 입력**:
   - **🏛️ KS/ISO 국가기술표준 (십진분류 · 격자표)**
   - **💼 대기업 전략기획 보고서 (개조식 기호 · 네이비 표)**
   - **🎓 국책연구원(KDI) 학술보고서 (장·절 체계 · 학술 표)**
   - **🚀 글로벌 빅테크 6-Pager (서술형 메모 · 모던 미니멀)**
   - **📱 SNS 카드뉴스 (인스타·링크드인 1:1 정사각 `sns_square`)**
   - **✍️ 한컴 타자 필사 문학 에디션 (미색 지류 · 감성 명조)**
2. **자연어 맞춤 프롬프트 작성 및 모델 선택**:
   - 원하는 글꼴, 색상, 제목 좌측 색깔바(`border-left`), 제목 번호 체계, 1~3단계 불릿 기호, 표 테두리, 표 상단·그림 하단 캡션 분리 등을 자유롭게 입력하고 **`[AI 서식 생성 실행]`**을 클릭하면 새 서식으로 자동 등록 및 적용됩니다.
   - 호출 한도 초과나 서버 혼잡 발생 시 대화형 진단 카드에서 다른 Gemini Flash 모델로 즉시 전환하여 재시도할 수 있습니다.

---

## 4. API 키 없이 외부 AI(ChatGPT · Claude · Gemini)로 서식 만들기 (`📖 최신 서식 생성 가이드`)

1. **`[📖 최신 서식 생성 가이드]`** 탭에서 **`[만능 마스터 프롬프트 복사하기]`** 버튼(또는 6대 표준 서식별 **`[외부 AI용 복사]`** 버튼)을 클릭합니다.
2. 사용 중인 ChatGPT, Claude, Gemini 채팅창에 붙여넣고 마지막 줄의 요청사항만 원하는 스타일로 수정하여 전송합니다.
3. AI가 출력한 JSON 코드를 복사한 뒤, **`[📤 가져오기 & 내보내기 허브]`** 탭에서 **`[클립보드 JSON 바로 불러오기]`**를 클릭하면 1초 만에 내 서식으로 등록됩니다.
