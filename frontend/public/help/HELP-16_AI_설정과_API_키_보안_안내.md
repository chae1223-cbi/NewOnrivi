# AI 연결·첨부·프롬프트 템플릿

## 이 도움말에서 해 볼 일

**AI 연결 상태 확인하기** — 사용할 AI 제공자의 API 키를 준비합니다.

### 따라 하기

1. 환경설정의 AI 연결 항목을 엽니다.
2. 사용할 제공자와 모델을 선택하고 API 키를 입력합니다.
3. 연동 테스트를 실행합니다.
4. 성공 여부를 확인한 뒤 짧은 문장으로 AI 작업을 시험합니다.

### 완료 확인

연동 테스트와 실제 짧은 요청이 모두 완료됩니다.

### 잘 안 될 때

실패하면 키의 유효성, 선택한 제공자, 인터넷 연결을 확인합니다. 키 전체를 화면 공유나 문의 글에 올리지 않습니다.

---

## 기능 자세히 알아보기

## 1. 구글 제미나이(Gemini) 무료 API 키 발급 5단계

Google AI Studio는 개인 창작자에게 매우 넉넉한 분량의 무료 API 호출 한도를 제공합니다:

1. 웹 브라우저에서 Google AI Studio(`aistudio.google.com`)에 접속하여 구글 계정으로 로그인합니다.
2. 좌측 상단 메뉴의 **[Get API key]**를 클릭합니다.
3. 파란색 **[Create API key]** 버튼을 누릅니다.
4. 신규 프로젝트에서 키를 생성(`Create API key in new project`)합니다.
5. 발급된 API 키 문자열(예: `AIzaSy...`)을 복사(`Copy`)합니다.

---

## 2. 온리비 어서 연동 및 최신 모델 선택

1. 온리비 어서 상단의 톱니바퀴(⚙️) 아이콘을 눌러 **[환경설정]** 모달을 엽니다.
2. [일반 설정] 탭 하단의 **'Google Gemini API Key'** 입력란에 복사한 키를 붙여넣습니다.
3. **[연동 테스트]** 버튼을 클릭합니다.
   - 시스템이 Google Generative Language API와 통신하여 키의 유효성을 검증하고, 현재 사용 가능한 최신 모델 목록을 실시간으로 가져옵니다.
4. **공인 모델 셀렉트박스 선택**:
   - 오타 입력을 방지하기 위해 텍스트 직접 입력란이 제거되고 공인 리스트박스로 단일화되었습니다.
   - **모델 선택**: 현재 설정 화면에 표시되는 사용 가능한 모델 중 목적에 맞는 것을 선택합니다.
   - **연동 테스트**: 선택한 모델로 짧은 요청을 보내 실제 연결을 확인합니다.
   - **`Gemma 4 (31B/26B IT)`**: 가볍고 정밀한 오픈 가중치 모델입니다.
5. 설정 창 하단의 **[저장]**을 누르면 연동이 즉시 완료됩니다.

---

## 3. 강력한 AES-256 키 보안 암호화 보관

- **로컬 암호화 격리**: 입력하신 API 키는 브라우저나 디스크에 평문(Plain text)으로 저장되지 않고, 강력한 AES-256 암호화 알고리즘을 거쳐 `U2FsdGVkX1...` 형태의 암호문으로 안전하게 보관됩니다.
- **리소스 폴더 실시간 동기화 (2026-10-21 패치)**: 공통 리소스 폴더가 연결되어 있다면 해당 폴더의 `ai-credentials.json` 보안 파일과도 자동으로 동기화되어, 환경설정 창을 열 때마다 항상 최신 자격정보가 유지됩니다.
- **연동 해제**: 더 이상 AI를 사용하고 싶지 않다면 언제든지 **[연동 해제]** 버튼을 눌러 저장된 키와 자격정보를 즉시 영구 삭제할 수 있습니다.
