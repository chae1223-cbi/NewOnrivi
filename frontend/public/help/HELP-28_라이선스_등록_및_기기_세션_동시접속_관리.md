# 라이선스·로그인·동시 접속 상태

## 1. 이 도움말에서 해 볼 일

**계정과 사용 상태 확인하기** — 로그인할 계정 정보를 준비합니다.

### 가. 따라 하기

1. 현재 로그인 상태를 확인합니다.
2. 계정 또는 라이선스 화면에서 사용 가능한 기능을 확인합니다.
3. 다른 기기에서 사용 중이라면 세션 목록과 제한 안내를 확인합니다.
4. 상태가 바뀐 뒤에는 문서를 다시 열어 편집 가능 여부를 확인합니다.

### 나. 완료 확인

현재 계정에서 사용할 수 있는 기능과 편집 가능 상태를 알 수 있습니다.

### 다. 잘 안 될 때

읽기 전용이면 먼저 문서 자체의 권한과 계정 상태를 각각 확인합니다.

## 3. 회원 등급 및 라이선스 권한 체계

| 회원 등급 | 편집 가능 여부 | 핵심 제공 기능 | 대상 사용자 |
| :--- | :---: | :--- | :--- |
| **Reader (비회원/게스트)** | **읽기 전용 (보호 모드)** | 원고 열람, 목차 탐색, 기본 HTML 복사 | 오탈자 방지 및 문서 검토자, 감수자 |
| **Apprentice (무료 플랜)** | **자유 편집 (제한 없음)** | 무제한 마크다운 저작, A4 실시간 조판, 기본 서식 갤러리 | 개인 작가, 블로거, 학생, 일반 창작자 |
| **Professional / Enterprise** | **자유 편집 + 고급 출판** | ePub 3.0 전자책, 인쇄용 무손실 PDF, Word/한글 오피스 변환, 지식보관함 RAG 검색 | 전문 출판 작가, 기업 기획팀, 연구원 |

- **Reader 모드의 안전 보호**: 라이선스를 등록하지 않은 상태에서는 실수로 타이핑하다가 원고가 지워지는 사고를 방지하기 위해 에디터가 읽기 전용(`readOnly`)으로 단단히 잠깁니다.
- **무료 활성화**: 대시보드에서 무료(Apprentice) 플랜을 선택하시면 즉시 에디터 잠금이 풀리고 자유롭게 글을 쓰실 수 있습니다.

## 4. 동시 접속 세션 관리 (Session Concurrency Guard)

- 여러 대의 PC나 노트북에서 동일한 계정으로 접속하는 경우, 계정 도용과 동시 수정 충돌을 방지하기 위해 **가장 최근에 로그인한 기기의 세션이 우선**됩니다.
- 이전 기기에서는 "다른 기기에서 로그인이 감지되었습니다"라는 안내창과 함께 안전하게 세션이 종료됩니다.

---

## 5. 오프라인 라이선스 보존 원리

- Electron 데스크톱 앱에서는 인증된 라이선스 키가 내 컴퓨터의 보안 스토리지에 암호화되어 안전하게 보관됩니다.
- 따라서 출장 중이거나 카페, 비행기 등 인터넷이 일시적으로 끊긴 환경에서도 프로그램이 차단되지 않고 정상적으로 원고를 집필하고 로컬 파일에 저장하실 수 있습니다.
