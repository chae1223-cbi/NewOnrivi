# 이미지·동영상·지도와 리소스 관리

## 이 도움말에서 해 볼 일

**이미지 첨부하고 경로 확인하기** — 삽입할 이미지 파일과 연결된 리소스 폴더를 준비합니다.

### 따라 하기

1. 문서에서 이미지를 놓을 위치에 커서를 둡니다.
2. 이미지 삽입 기능 또는 붙여넣기로 파일을 첨부합니다.
3. 본문에 이미지가 표시되는지, 문서 저장 후 다시 열어도 보이는지 확인합니다.
4. 다른 컴퓨터로 옮길 때는 원고와 이미지 폴더를 함께 복사합니다.

### 완료 확인

문서를 다시 열어도 이미지가 표시됩니다.

### 잘 안 될 때

이미지가 깨지면 파일이 실제로 존재하는지와 문서에 적힌 경로를 먼저 확인합니다.

---

## 기능 자세히 알아보기

## 1. 이미지 삽입 3대 방법

1. **클립보드 붙여넣기 (`Ctrl + V` - 가장 추천)**:
   - 화면 캡처 도구나 웹에서 복사한 이미지를 에디터 커서 위치에서 바로 붙여넣으면, 연결된 공통 리소스 폴더의 `media/` 하위에 자동 저장되며 본문에는 상대경로로 즉시 기재됩니다.
2. **파일 드래그 앤 드롭 (Drag & Drop)**:
   - 내 컴퓨터 탐색기에 있는 이미지 파일(`.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.svg`)을 마우스로 끌어 에디터 창에 놓으면 자동으로 복사 및 삽입됩니다.
3. **상단 툴바의 [이미지 삽입] 버튼**:
   - 툴바의 사진 아이콘을 클릭하여 파일 탐색기에서 이미지를 선택하거나 웹 이미지 URL을 직접 입력할 수 있습니다.

---

## 2. 상대경로 관리 원리와 데이터 주권 (내 PC & 개인 웹드라이브)

- 삽입된 이미지는 마크다운 본문에 다음과 같이 상대경로 형식으로 기록됩니다:
  ```markdown
  ![[그림 1] 시스템 설정 화면](./media/settings_preview.png)
  ```
- **왜 상대경로(`./media/`)인가요?**:
  - 절대경로(`C:\Users\username\...`)로 저장되면 다른 컴퓨터로 문서를 옮겼을 때 이미지가 깨지는 문제가 발생합니다.
  - 온리비 어서처럼 `./media/` 상대경로를 사용하면, 원고 폴더와 리소스 폴더를 함께 압축하여 다른 작가나 출판사에 전달해도 이미지가 100% 정상 표시됩니다.

---

## 3. 이미지 크기와 하단 캡션 조절

- **너비 조절**: HTML 문법을 결합하여 `width` 속성으로 이미지의 표시 너비를 쉽게 제어할 수 있습니다:
  ```markdown
  <img src="./media/chart.png" width="80%" alt="성장 분석 차트" />
  ```
  *(본문 너비 대비 80% 크기로 단정하게 배치됩니다.)*
- **그림 캡션(제목) 권장 작성법**:
  - 온리비 어서는 대괄호 `![설명](경로)` 안의 텍스트를 출판 표준 `<figcaption>` 캡션으로 자동 변환하여 정갈한 간격으로 배치합니다.
    ```markdown
    ![[그림 1] 시스템 설정 화면](./media/settings_preview.png)
    ```
  - **주의**: 대괄호에 설명을 넣은 상태에서 이미지 바로 아래에 `*[그림 1]...*`을 중복 작성하면 캡션이 두 줄로 겹쳐 뭉쳐 보일 수 있습니다. 대괄호 안에 온전한 제목을 넣거나, 아래 줄에 별도 텍스트를 쓸 때는 대괄호를 비우고(`![](...)`) 빈 줄을 둔 후 작성하시길 권장합니다.

---

## 4. YouTube 동영상 및 지도 임베드

- **YouTube 동영상**:
  - 상단 메뉴의 [도구] ➔ [동영상 삽입]을 누르거나, 동영상 공유 링크(`https://youtu.be/...`)를 입력하면 반응형 동영상 플레이어가 미리보기에 임베드됩니다.
- **도움말 시스템 정적 자산 로드 보호 (2026-10-14 패치)**:
  - 시스템 도움말 이미지(`/help/assets/` 및 `./assets/`)는 사용자 리소스 폴더로 오탐되지 않고, 데스크톱 앱 내부 정적 로더(`app://`) 및 웹 정적 라우트로 100% 직결되므로 리소스 폴더 지정 여부와 상관없이 항상 선명하게 렌더링됩니다.
