# 🎨 나만의 커스텀 서식 설계와 15대 상세 설정 (HELP-13)

시스템 기본 서식을 복제하거나 서식 관리 센터의 **`+ 추가`** 버튼으로 새 서식을 만든 뒤, 좌측 **서식 편집기(`CssStyleForm`)**에서 코딩 없이 모든 디자인 요소를 세밀하게 조정할 수 있습니다.

---

## 1. 새 커스텀 서식 만들기 (2가지 방법)

1. **서식 관리 센터에서 문서 타입별 생성**:
   - **`서식 관리`** 모달 좌측 상단의 **`+ 추가`** 버튼을 클릭해 **`📄 일반문서`**, **`📖 그림책(전체표지)`**, **`📖 그림책(오른쪽표지)`**, **`📱 SNS 카드뉴스`** 4종 중 원하는 타입으로 새 서식을 생성합니다.
2. **기존 서식 복제 후 편집**:
   - 마음에 드는 시스템 서식이나 기존 서식 우측의 **`[서식 복제]`** 아이콘을 클릭하면 모든 속성(`pageStyle`, `rules`, `tableStructure`, `bulletStructure`, `mediaCaptionStructure`, `headingNumbering` 등)이 100% 보존된 사본이 생성됩니다.

---

## 2. 2단계 편집 모드 전환 (`간편 스타일링` vs `세부 서식 다듬기`)

좌측 서식 편집 패널 상단의 모드 전환 버튼으로 작업 수준에 맞게 전환할 수 있습니다.

### 2.1 ⚡ 간편 스타일링 (Simple Mode — `QuickStylePanel`)
복잡한 세부 수치 없이 문서 전체의 인상을 결정하는 핵심 요소를 한 화면에서 빠르게 설정합니다.
- **글꼴(Font Family) & 기본 활자 크기(pt) / 줄간격 / 배경색**
- **용지 규격(`A4`, `B5`, `Letter`, `SNS 1:1 정사각`, `SNS 4:5 세로형`) & 용지 방향(`세로`/`가로`) & 사방 여백(`mm`)**
- **제목 자동 번호 체계(`headingNumbering`) 프리셋**: 번호 없음, 십진 분류(`1. ➔ 1.1`), 학술 장·절(`제1장 ➔ 제1절`), 대기업 개조식(`□ ➔ ○ ➔ -`) 등 원클릭 적용
- **표 테두리 3대 프리셋**: 가로선 강조형(논문/보고서), 모든 테두리 격자형(KS/공문서), 미니멀형
- **1~3단계 글머리 기호(`bulletStructure`) 및 캡션 위치(`mediaCaptionStructure`) 빠른 설정**

### 2.2 🎨 세부 서식 다듬기 (Detail Mode — 15대 카테고리 전수 제어)
상단 고정 카테고리 탭(빠른 검색 지원)과 하단 **`[◀ 이전 서식] [현재 서식 배지 (1~15 팝업 선택기)] [다음 서식 ▶]`** 내비게이션 바를 통해 **15대 상세 카테고리**를 정밀하게 다듬습니다.

| 번호 | 카테고리 | 주요 제어 속성 및 프리셋 |
| :---: | :--- | :--- |
| **1** | **본문·여백** (`p`, `strong`, `em`, `u`, `del`) | 본문 활자 크기(`pt`, 4대 규격 프리셋 + 0.5pt 슬라이더), 줄간격, 문단 간격, 문장 간격(`sentence-gap`), 첫 줄 들여쓰기, 정렬, 사방 여백(`mm`), 탭 너비, 인라인 강조 4종(굵게 형광펜 배경, 기울임, 밑줄 모양·두께·간격, 취소선 색상·두께·투명도) |
| **2** | **제목** (`h1`~`h6`) | H1 기준 크기(`pt`) 및 **단계별 크기 감소폭(`headingSizeOffset`, 미정의 시 기본값 `3pt`, `0pt`~`6pt` 조절)**, **제목 앞 좌측 색깔바(`border-left`: 바 없음 / 3px / 4px / 6px + 색깔바 색상 선택 + 좌측 여백 `12px` 자동 연동)**, 하단 밑줄(없음/실선/관보 이중선), 상하 여백, H1~H6 단계별 번호·기호 커스텀 설정 |
| **3** | **표** (`table`, `th`, `td`) | 표 형태 3대 프리셋(가로선 강조 / 모든 테두리 격자 / 미니멀), 외곽·행·열 테두리 두께(`tableStructure`) 및 선 모양·색상, 헤더(`th`)·본문(`td`) 배경색/글자색/정렬/셀 안쪽 여백(`padding`), 표 활자 크기(`pt`) |
| **4** | **인용구** (`blockquote`) | 3대 형태 프리셋(왼쪽 띠형 `border-left` / 전체 박스형 `border` / 그림자 박스형 `box-shadow`), 배경색, 글자색, 모서리 둥글기, 안쪽 여백 |
| **5** | **코드블록** (`codeBlock`, `codeBlockTitle`) | 3대 테마 프리셋(라이트 기본 박스 / Mac OS 다크 테마 / 다크 네이비 고정), 코드 본문 및 상단 타이틀바 배경색·글자색, 활자 크기(`pt`), 줄간격, 테두리 |
| **6** | **인라인코드** (`code`) | 배경색, 글자색, 굵기, 테두리 두께·색상, 모서리 둥글기(`border-radius`), 좌우·상하 안쪽 여백 |
| **7** | **하이퍼링크** (`a`) | 링크 글자색, 밑줄 표시 여부(`underline` / `none`), 글자 굵기 |
| **8** | **각주** (`footnote`) | 각주 활자 크기(`pt`), 글자색, 굵기, 줄간격, 상하 여백 |
| **9** | **목록·체크** (`ul`, `ol`, `li`, `taskList`) | 숫자 목록 체계(`decimal`, 원문자 `onrivi-circled-decimal` ①②③, 한국형 보고서 `onrivi-report` Ⅰ.→1.→가.→1)→가)), **1~3단계 글머리 기호 13종(`•`, `○`, `■`, `▫`, `◆`, `◇`, `-`, `–`, `▶`, `✓`, `★`, `·`, 직접 입력 `custom`)**, 목록 들여쓰기, 기호-텍스트 간격(`padding-inline-start`), 체크박스 크기·간격·완료 효과(`checkboxStructure`) |
| **10** | **구분선** (`hr`) | 선 모양(`solid` 실선 / `dotted` 점선 / `dashed` 파선 / `double` 이중선), 두께(`1px`~`10px`), 가로 폭 비율(`100%`/`75%`/`50%`/`30%`), 상하 여백, 색상(`hrStructure`) |
| **11** | **이미지** (`img`) | 3대 액자 프리셋(기본형 / 폴라로이드형 / 둥근 썸네일형), 가로 폭(`width`), 모서리 둥글기, 그림자, 좌·중·우 정렬, **표·이미지·비디오·지도 캡션 위치(상단/하단) 및 6종 구문 포맷(`그림 1.`, `[그림 1]`, `<표 1>`, 커스텀 템플릿, `kindOverrides` 대상별 분리)** |
| **12** | **비디오** (`video`) | 가로 폭(`100%`), 높이(`315px`~`450px`), 모서리 둥글기, 그림자, 좌·중·우 정렬, 상하 여백 |
| **13** | **지도** (`map`) | 가로 폭(`100%`), 높이(`400px`), 모서리 둥글기, 그림자, 좌·중·우 정렬, 상하 여백 |
| **14** | **수식** (`math`) | 수식 글자색, 활자 크기(`pt`), 좌·중·우 정렬, 상하 여백 |
| **15** | **고급 CSS** (`customCss`) | 미리보기 루트(`.custom-preview-container`) 하위에 적용할 사용자 정의 CSS 직접 작성 |

---

## 3. 쇼케이스 클릭 연동 및 가이드 다운로드

- 미리보기 쇼케이스에서 수정하고 싶은 요소(예: 표, 인용구, 각주, 코드블록 등)를 직접 클릭하면 좌측 편집기가 해당 카테고리 패널로 자동 전환됩니다.
- 좌측 서식 패널 상단의 **`📖 서식 설정 가이드`** 버튼을 누르면 15대 카테고리 전체 속성이 수록된 최신 레퍼런스(`Onrivi_CSS_Profile_Guide.md`)를 다운로드할 수 있습니다.
