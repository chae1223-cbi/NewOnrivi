# 무엇을 도와드릴까요?

온리비 어서에서 문서를 처음 만들거나, 작업 중 막힌 부분을 해결할 때 필요한 안내를 찾아보세요. 처음 사용한다면 **5분 시작하기**부터 따라 해 보세요. 이미 원고가 있다면 아래에서 하려는 작업을 선택하면 됩니다.

### 가. 처음 사용하시나요?

**[5분 시작하기](./HELP-01_온리비_어서_소개와_시작하기.md)**  
작업장을 열고, 첫 문서를 만들고, 저장한 뒤 PDF 출력 화면까지 확인합니다. 마크다운 문법을 몰라도 따라 할 수 있습니다.

**기존 문서를 여시나요?**  
파일 탐색기에서 문서를 선택하고, 수정 전에 저장 위치와 읽기 전용 상태를 확인하세요. 작업장 연결 방법은 [작업 환경 연결](./HELP-04_작업_환경_연결.md)에 있습니다.

### 나. 하고 싶은 일을 선택하세요

#### 1) 문서 쓰기

- **글 입력과 편집** — 문서보기와 나란히 보기 중 편한 화면을 고르고, 외부 글을 붙여넣습니다. [본문 입력](./HELP-05_3대_본문_입력_방식.md)
- **제목과 문단 정리** — 제목 단계, 줄바꿈, 강조, 링크를 사용합니다. [마크다운 기본](./HELP-06_마크다운_기본_문법과_줄바꿈_링크.md)
- **목록과 체크리스트** — 순서 있는 목록과 할 일을 만듭니다. [목록 안내](./HELP-07_목록과_할_일_체크리스트.md)
- **표와 이미지 넣기** — 자료를 표로 정리하고 이미지를 첨부합니다. [표 안내](./HELP-09_표_작성과_텍스트_정렬_가이드.md) · [이미지 안내](./HELP-10_이미지_미디어_첨부와_리소스_경로_관리.md)

#### 2) 문서 꾸미고 결과물 만들기

- **서식 선택** — 문서 목적에 맞는 제공 서식을 적용하고 결과를 확인합니다. [서식 관리](./HELP-11_서식_관리_센터와_시스템_제공_서식.md)
- **PDF로 저장하거나 인쇄** — 인쇄/PDF 출력 화면에서 용지와 쪽 윤곽을 확인합니다. [PDF 출력](./HELP-22_인쇄_출판용_고품질_PDF_내보내기.md)
- **다른 형식으로 내보내기** — [EPUB](./HELP-21_전자책_EPUB_제작과_제출_전_점검_사항.md) · [Word와 HWPX](./HELP-23_Word_HWP_가져오기와_DOCX_HWPX_내보내기.md) · [HTML](./HELP-24_블로그_포스팅용_HTML_간편_복사.md)

#### 3) 기능 더 활용하기

- **AI 글쓰기** — AI 연결 설정을 확인하고 문장 수정이나 초안 작성을 시작합니다. [AI 활용](./HELP-15_AI_글쓰기_어시스턴트_활용법.md) · [AI 설정](./HELP-16_AI_설정과_API_키_보안_안내.md)
- **자료 찾기** — 지식보관함에 자료를 등록하고 검색합니다. [지식보관함](./HELP-17_지식보관함_색인과_참조_검색.md)
- **빠르게 입력하기** — [슬래시 명령](./HELP-25_슬래시_명령어와_플로팅_서식_툴바.md) · [단축키](./HELP-26_키보드_단축키_마스터와_사용자_정의.md)

### 다. 문제가 생겼나요?

| 증상 | 먼저 확인할 것 | 자세한 안내 |
| --- | --- | --- |
| 저장했는데 내용이 보이지 않음 | 현재 연 문서와 작업장 폴더, 저장 표시 | [저장과 세션 복구](./HELP-03_문서_저장과_세션_자동_복구의_차이.md) |
| 파일이나 폴더를 열 수 없음 | 작업장 연결 상태와 브라우저 폴더 권한 | [작업 환경 연결](./HELP-04_작업_환경_연결.md) |
| 이미지가 보이지 않음 | 이미지 파일의 위치와 원고의 경로 | [이미지와 리소스 경로](./HELP-10_이미지_미디어_첨부와_리소스_경로_관리.md) |
| PDF 모양이 예상과 다름 | 선택한 서식, 용지·여백, 쪽 윤곽 | [인쇄와 PDF](./HELP-22_인쇄_출판용_고품질_PDF_내보내기.md) |
| AI 기능을 사용할 수 없음 | 연결 설정과 API 키 상태 | [AI 설정](./HELP-16_AI_설정과_API_키_보안_안내.md) |

위 항목으로 해결되지 않으면 [문제 해결과 자주 묻는 질문](./HELP-29_문제_해결과_자주_묻는_질문.md)을 확인하세요.
