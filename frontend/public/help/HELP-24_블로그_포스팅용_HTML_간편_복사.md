# HTML 내보내기와 서식 포함 복사

## 이 도움말에서 해 볼 일

**블로그용 HTML 준비하기** — 게시할 문서를 저장합니다.

### 따라 하기

1. 본문 제목·이미지·링크를 점검합니다.
2. 파일 → 내보내기에서 HTML 파일을 선택하거나 제공되는 HTML 복사 기능을 사용합니다.
3. 브라우저나 블로그 편집기에 결과를 붙여넣어 확인합니다.
4. 게시 전에 외부 링크와 이미지 표시를 다시 확인합니다.

### 완료 확인

대상 화면에서 제목, 문단, 이미지가 의도대로 보입니다.

### 잘 안 될 때

서식이 바뀌면 대상 서비스가 허용하는 HTML과 스타일 범위를 확인합니다.

---

## 기능 자세히 알아보기

## 1. 원클릭 [HTML 서식 포함 복사] 기능

- **작동 원리**:
  - 일반적인 복사는 단순 텍스트만 복사되지만, 온리비 어서의 **[HTML 서식 복사]** 버튼을 누르면 클립보드에 인라인 스타일(CSS Inline Style)이 각 태그마다 입혀진 채로 복사됩니다.
- **사용 방법**:
  1. 에디터 우측 상단의 **[HTML 복사]** 버튼을 누르거나, 단축키 `Ctrl + Shift + C`를 누릅니다.
  2. 하단 상태바에 "클립보드에 서식 포함 HTML이 복사되었습니다"라는 알림이 뜹니다.
  3. 네이버 블로그 스마트에디터나 티스토리 글쓰기 창으로 이동하여 **`Ctrl + V`**로 붙여넣습니다.
  4. 클릭 한 번으로 제목 색상, 표의 예쁜 테두리와 배경색, 인용구 박스, 콜아웃 스타일이 블로그 화면에 그대로 재현됩니다.

---

## 2. 독립된 HTML 파일 내보내기 (Export as HTML)

웹 서버에 바로 업로드하거나 이메일 첨부 파일로 보낼 수 있는 단일 HTML 파일로 저장하는 방법입니다:

- [파일] ➔ [내보내기] ➔ [HTML 파일]을 선택합니다.
- CSS 스타일이 `<style>` 태그로 완전히 내장된 단독 실행형 HTML 파일이 생성됩니다.
- 인터넷이 연결되지 않은 환경에서도 브라우저 더블클릭만으로 온리비 어서의 아름다운 출판 서식 그대로 열람할 수 있습니다.
