# 5분 시작하기 — 첫 문서를 만들고 PDF로 확인하기

> 검토용 사용자 원고 · 2026-11-05. 메뉴 경로는 현재 코드를 기준으로 정리했으며, 웹·데스크톱 화면에서 게시 전 최종 확인이 필요합니다.

온리비 어서를 처음 사용한다면 이 안내를 따라 짧은 원고 하나를 완성해 보세요. 작업장을 열고 문서를 만든 뒤, 내용을 저장하고 인쇄/PDF 화면에서 결과를 확인합니다. 처음부터 서식이나 마크다운 문법을 익힐 필요는 없습니다.

**준비할 것:** 원고를 보관할 폴더 하나와 작성할 문서 이름. 예시에서는 `첫 문서`라는 이름을 사용합니다.

## 1. 원고를 둘 작업장 열기

작업장은 문서 파일을 보관하고 왼쪽 파일 탐색기에서 보여 주는 폴더입니다. 먼저 저장할 곳을 직접 선택합니다.

1. 상단 **파일** 메뉴를 열고 **작업장 열기**를 선택합니다.
2. 원고를 보관할 폴더를 선택합니다. 이미 문서가 든 폴더를 골라도 됩니다.
3. 웹에서 브라우저가 폴더 접근 권한을 요청하면 내용을 확인한 뒤 허용합니다.
4. 왼쪽 파일 탐색기에 선택한 폴더와 그 안의 문서가 나타나는지 확인합니다.

**완료 확인:** 왼쪽에서 작업장 폴더를 볼 수 있습니다. 폴더가 보이지 않거나 접근 권한을 다시 요청한다면 새 문서를 만들기 전에 연결 상태를 확인하세요. 웹과 데스크톱의 연결 방법은 [작업 환경 연결](../frontend/public/help/HELP-04_작업_환경_연결.md)에 더 자세히 설명되어 있습니다.

## 2. 새 문서 만들기

1. 상단 **파일 → 새 문서**를 선택합니다. 문서 탭 옆 **+** 또는 **Ctrl+N**으로도 새 문서 창을 열 수 있습니다.
2. 파일 이름 칸에 `첫 문서`를 입력합니다.
3. 저장할 폴더를 선택합니다. 방금 연 작업장에 바로 저장하려면 작업장 루트를 선택합니다.
4. 만들기 버튼을 누릅니다. 파일 이름 끝의 `.md`는 자동으로 붙으므로 직접 입력하지 않아도 됩니다.

**완료 확인:** `첫 문서.md`가 왼쪽 파일 탐색기와 상단 문서 탭에 표시됩니다.

같은 폴더에 동일한 이름의 문서가 이미 있으면 다른 이름을 입력하세요. 파일 이름에 `\ / : * ? " < > |` 같은 문자는 사용할 수 없습니다.

## 3. 본문에 제목과 문단 넣기

새 문서의 본문에 아래처럼 짧게 적어 보세요. 화면이 문서보기라면 일반 문서처럼 제목과 문장을 입력하면 됩니다.

> 첫 문서  
>   
> 오늘은 온리비 어서에서 처음으로 문서를 작성했습니다.  
> 작성한 내용을 저장하고 PDF로 확인해 보겠습니다.

제목을 정식 제목 스타일로 바꾸려면 제목 줄을 선택하고 서식 도구에서 제목을 적용할 수 있습니다. 마크다운 입력에 익숙하다면 줄 맨 앞에 `# `를 입력해 제목을 만들 수도 있습니다. 처음에는 내용 입력과 저장에만 집중해도 됩니다.

**완료 확인:** 입력한 제목과 문단이 본문에 보입니다. 문서보기·나란히 보기 등 입력 화면이 헷갈린다면 [본문 입력과 붙여넣기](../frontend/public/help/HELP-05_3대_본문_입력_방식.md)를 참고하세요.

## 4. 원고 파일 저장하기

본문을 입력했다면 **Ctrl+S**를 누릅니다. Mac에서는 **Cmd+S**를 사용합니다. 저장 후 왼쪽 파일 탐색기에서 방금 만든 문서가 있는지 확인하세요. 가능하다면 다른 문서를 잠시 열었다가 다시 돌아와 입력한 내용이 남아 있는지도 확인해 보세요.

온리비 어서에는 자동 저장과 세션 복구 기능도 있지만, 둘은 직접 파일에 저장하는 동작과 역할이 다릅니다. 작업을 마친 뒤에는 저장 상태를 확인하는 습관이 좋습니다. 차이는 [저장·자동 저장·세션 복구](../frontend/public/help/HELP-03_문서_저장과_세션_자동_복구의_차이.md)에서 확인할 수 있습니다.

**완료 확인:** `첫 문서.md`를 다시 열어도 제목과 문단이 그대로 보입니다.

## 5. 서식을 고르고 PDF 출력 화면 열기

서식을 바꾸지 않아도 출력은 할 수 있습니다. 문서의 글꼴과 여백을 조정하고 싶다면 먼저 **서식 관리**를 열어 제공 서식 중 하나를 선택하고 본문에 반영된 모습을 확인하세요. 서식별 차이는 [서식 관리](../frontend/public/help/HELP-11_서식_관리_센터와_시스템_제공_서식.md)에 있습니다.

이제 출력 화면을 엽니다.

1. 상단 **파일 → 내보내기**를 선택합니다. 통합 출력 창이 열립니다.
2. 출력 형식에서 **인쇄 / PDF 출력**을 선택합니다.
3. 필요하면 **쪽 윤곽 미리보기**를 펼쳐 페이지 구성을 확인합니다. 이 미리보기는 출력 창을 열었다고 자동으로 실행되지는 않습니다.
4. **인쇄 / PDF 저장**을 눌러 운영체제의 인쇄 화면을 엽니다.
5. 종이에 인쇄하려면 프린터를, 파일로 보관하려면 인쇄 화면의 PDF 저장 항목을 선택합니다.

**완료 확인:** 인쇄 화면에서 문서 제목과 본문이 보입니다. PDF로 저장했다면 선택한 위치에서 파일을 열어 제목, 문단, 페이지 구성을 확인하세요. 용지·여백·쪽 나누기는 [페이지 나누기와 인쇄·PDF 출력](../frontend/public/help/HELP-22_인쇄_출판용_고품질_PDF_내보내기.md)에 설명되어 있습니다.

## 잘 안 될 때

| 상황 | 확인할 것 | 다음 행동 |
| --- | --- | --- |
| 새 문서 창에서 폴더를 고를 수 없음 | 작업장이 먼저 연결되었는지 | 1단계로 돌아가 작업장을 엽니다. |
| 같은 이름의 문서가 있다고 나옴 | 선택한 폴더와 파일 이름 | 새 이름을 쓰거나 다른 폴더를 선택합니다. |
| 저장 후 내용이 없어 보임 | 현재 문서 탭과 작업장 위치 | 같은 파일을 다시 열고 [저장 안내](../frontend/public/help/HELP-03_문서_저장과_세션_자동_복구의_차이.md)를 확인합니다. |
| PDF에서 줄바꿈이나 쪽 구성이 다름 | 적용된 서식, 용지, 여백 | 출력 창의 쪽 윤곽과 [PDF 안내](../frontend/public/help/HELP-22_인쇄_출판용_고품질_PDF_내보내기.md)를 확인합니다. |
