# 🏛️ 서식 관리 센터와 시스템 제공 서식 (HELP-11)

온리비 어서는 작성한 마크다운 원고를 단 한 줄도 수정하지 않고, 서식 프로필(CSS Profile)만 교체하여 정부 공문서, 대기업 전략 보고서, 국책연구원 논문, 테크 블로그, SNS 카드뉴스, 그림책(스토리북) 등 다양한 출판 레이아웃으로 즉시 변환합니다.

---

## 1. 서식 관리 센터 열기 및 화면 구성

상단 메뉴바의 **`서식 관리`** 또는 좌측 서식 편집 패널 상단의 **`⚙ 서식 관리`** 버튼을 클릭하면 **서식 관리 센터** 모달이 열립니다.

### 1.1 좌측 사이드바 (서식 탐색 및 원클릭 액션)
- **전체 백업**: 내가 만든 모든 커스텀 서식을 단일 JSON 배열 파일(`Onrivi_내서식_백업_YYYYMMDD.json`)로 한 번에 백업합니다.
- **`+ 추가` (4종 문서 타입 선택 생성)**:
  - **`📄 일반문서`**: `Onrivi 기본서식` 기반 표준 A4 문서 서식을 생성합니다.
  - **`📖 그림책(전체표지)`**: 표지 전체에 일러스트가 배치되는 스토리북 레이아웃(`cover: "full-image"`) 서식을 생성합니다.
  - **`📖 그림책(오른쪽표지)`**: 우측에 표지 이미지가 배치되는 스토리북 레이아웃(`cover: "image-right"`) 서식을 생성합니다.
  - **`📱 SNS 카드뉴스`**: 인스타그램·링크드인용 1:1 정사각(`paperSize: "sns_square"`) 카드뉴스 서식을 생성합니다.
- **분류 필터 탭**: **`전체` / `내 서식` / `시스템` / `그림책`** 탭과 실시간 검색창으로 원하는 서식을 빠르게 찾습니다.
- **서식 항목별 4대 원클릭 액션**: 각 서식 우측 아이콘으로 **`[서식 복제] · [파일 내보내기(.json)] · [클립보드 JSON 복사] · [삭제(내 서식)]`**를 즉시 실행할 수 있습니다.

### 1.2 우측 본문 상단 2단 요약 카드 & 실시간 미니 조판 미리보기
- **좌측 `[이름 및 서식 설명 카드]`**: 현재 선택된 서식의 이름(내 서식은 인라인 수정 가능), 문서 타입 배지(`일반문서` / `SNS 카드뉴스` / `그림책`), 상세 설명을 표시하고 **`[서식 세부 편집하기]`** 버튼으로 좌측 15대 상세 서식 편집기로 즉시 이동합니다.
- **우측 `[📋 설명 상세 카드]`**: **① 글꼴 · ② 크기/행간 · ③ 여백 · ④ 표 테두리(외곽/행/열) · ⑤ 불릿(1~3단계 기호) · ⑥ 문서 타입** 6대 핵심 사양을 한눈에 요약합니다.
- **`[실시간 미니 조판 미리보기]`**: 대제목(H1)·중제목(H2) 좌측 색깔바/밑줄/번호, 본문, 1~3단계 불릿, 인용구, 표 테두리 및 표·이미지 캡션 위치를 실시간으로 미리 보여줍니다.

## 2. 주요 시스템 제공 서식 (`🏛️ 시스템`)

시스템 기본 서식은 원본 보호를 위해 읽기 전용(`Read-Only`)으로 제공되며, 수정이 필요할 때는 **`[서식 복제]`** 버튼을 눌러 내 서식으로 복제한 뒤 자유롭게 편집할 수 있습니다.

| 서식 이름 | 문서 타입 / 규격 | 핵심 조판 특징 |
| :--- | :--- | :--- |
| **Onrivi 기본서식** | 일반문서 (`a4`) | 온리비 공식 기본 테마 (본문 16px, 줄간격 1.75, 상하 18mm·좌우 12mm 표준 여백, 제목 단계별 감소폭 `3pt`) |

## 3. 서식 전환 및 쇼케이스 미리보기

1. 에디터 좌측 사이드바에서 **`🎨 서식 설정`** 아이콘을 열거나 서식 관리 센터에서 원하는 서식을 클릭하면 우측 미리보기에 즉시 반영됩니다.
2. 문서가 비어 있거나 서식을 점검하고 싶을 때는 **15대 서식 쇼케이스 화면**을 통해 제목, 본문, 표, 인용구, 코드블록, 목록, 수식, 미디어 캡션 등 모든 요소의 조판 상태를 한눈에 확인하고 클릭하여 해당 세부 설정 탭으로 바로 이동할 수 있습니다.
