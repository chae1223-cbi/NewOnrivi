# 문서 가져오기와 Word·HWPX 내보내기

## 이 도움말에서 해 볼 일

**Word와 HWPX 결과 확인하기** — 원본 문서를 저장하고 표나 이미지를 점검합니다.

### 따라 하기

1. 파일 → 내보내기를 엽니다.
2. 필요한 형식인 Word 문서 또는 한글 문서를 선택합니다.
3. 파일을 저장하고 해당 편집 프로그램에서 다시 엽니다.
4. 제목 단계, 표, 이미지, 페이지 구성을 원본과 비교합니다.

### 완료 확인

내보낸 파일이 대상 프로그램에서 열리고 주요 콘텐츠가 보입니다.

### 잘 안 될 때

배치가 달라지면 대상 프로그램의 글꼴 설치와 페이지 설정을 먼저 확인합니다.

---

## 기능 자세히 알아보기

## 1. 기존 문서 가져오기 (Import)

기존에 다른 워드프로세서로 작성해 둔 원고를 온리비 어서로 가져와 마크다운으로 전환하는 방법입니다:

- **지원 형식**: `.docx` (MS Word), `.hwp` (아래아한글 구버전), `.txt` (순수 텍스트)
- **가져오기 절차**:
  1. 상단 메뉴의 [파일] ➔ [가져오기]를 선택합니다.
  2. 내 컴퓨터에서 가져올 오피스 문서 파일을 선택합니다.
  3. 온리비 어서의 지능형 문서 변환 파이프라인이 제목 계층, 문단, 글머리기호, 표 구조를 분석하여 순수한 표준 마크다운 원문으로 자동 변환해 줍니다.
  4. 변환된 문서를 확인하고 새 마크다운 파일(`.md`)로 저장합니다.

---

## 2. Word(`.docx`) 및 한글(`.hwpx`) 내보내기 (Export)

내가 작성한 마크다운 문서를 거래처, 출판사, 공공기관에 제출해야 할 때 상용 오피스 파일로 즉시 변환합니다:

- **내보내기 절차**:
  1. 상단 메뉴의 [파일] ➔ [내보내기]를 열고 **[Word (.docx)]** 또는 **[한글 (.hwpx)]** 탭을 선택합니다.
  2. [내보내기 실행] 버튼을 누르면 브라우저/앱이 표준 오피스 바이너리 패키징을 생성하여 즉시 다운로드해 줍니다.
- **오피스 변환 시 보존되는 서식 요소들**:
  - H1~H6 제목 스타일 및 글꼴 크기
  - 표(Table)의 테두리, 배경색, 열 너비 비율 및 셀 정렬
  - 본문에 첨부된 로컬 이미지의 인라인 패키징 (외부 링크가 아닌 문서 내부에 포함)
  - 글머리기호 목록 및 번호 매기기

> [!NOTE]
> 최신 한글 표준 규격인 `.hwpx`(OWPML 개방형 문서 규격)로 출력되므로, 한컴오피스 2014 이후의 모든 버전 및 한컴 웹독스에서 완벽히 열람하고 편집할 수 있습니다.
