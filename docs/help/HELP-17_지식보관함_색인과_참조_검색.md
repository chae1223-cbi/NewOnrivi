# 지식보관함 등록·색인·검색·근거 확인

## 이 도움말에서 해 볼 일

**자료 등록하고 검색하기** — 출처를 확인할 수 있는 문서 파일을 준비합니다.

### 따라 하기

1. 지식보관함에서 등록할 문서를 고릅니다.
2. 색인이 완료될 때까지 기다린 뒤 목록에서 문서를 확인합니다.
3. 본문에 있는 고유 단어로 검색합니다.
4. 검색 결과에서 원문 위치와 출처를 열어 확인합니다.

### 완료 확인

등록한 문서가 목록에 있고 검색 결과에서 원문을 찾을 수 있습니다.

### 잘 안 될 때

검색 결과가 없으면 색인 완료 여부와 검색어의 원문 표기를 확인합니다.

---

## 기능 자세히 알아보기

## 1. 지식보관함 아키텍처와 로컬 무결성

- **로컬 고속 FTS5 전문 색인**: 문서를 외부 클라우드 벡터 DB로 업로드하지 않고, 내 컴퓨터의 경량 고속 데이터베이스인 SQLite FTS5(Full-Text Search) 엔진을 통해 로컬에서 직접 형태소 분석 및 전문 색인을 수행합니다.
- **SQLite 원트랜잭션(All-or-Nothing) 무결성 보장**:
  - 시스템 개발 규칙에 따라 외부 I/O 및 전처리가 100% 정상 완료된 이후에만 원자적 단일 트랜잭션(`BEGIN TRANSACTION; ... COMMIT;`)으로 DB에 안전하게 기록됩니다.
  - 처리 중 오류가 발생하면 즉시 전면 롤백되어 불완전한 찌꺼기 데이터가 절대 남지 않습니다.

---

## 2. 지식보관함 문서 등록 및 색인 방법

1. 상단 메뉴의 [도구] ➔ [지식보관함]을 열거나 좌측 사이드바의 지식보관함 탭을 선택합니다.
2. **[문서 가져오기]**를 눌러 내 작업장의 마크다운 파일(`.md`)이나 텍스트 자료를 선택합니다.
3. 시스템이 문서를 읽어 적절한 청크(Chunk) 단위로 자동 분할하고 제목, 키워드, 본문 색인을 생성합니다.
4. 등록이 완료되면 지식보관함 목록에 문서명, 등록 일시, 청크 개수, 요약문이 고대비로 선명하게 표시됩니다.

---

## 3. 내 원고 기반 근거 확인 질의응답 (Grounding QA)

지식보관함에 원고를 등록해 두면, AI 어시스턴트에게 다음과 같이 내 자료에 기반한 질문을 던질 수 있습니다:

- *"작년 3분기 사업계획서에서 언급했던 마케팅 핵심 전략 3가지를 정리해줘."*
- *"소설 1부 3장에서 주인공이 만났던 조력자의 이름과 대사를 찾아줘."*
- **출처 및 근거 하이라이트**:
  - AI는 허구의 사실(환각 현상)을 지어내지 않고, 지식보관함에서 검색된 실제 원고의 문단을 근거로 답변을 작성합니다.
  - 답변 하단에 **[참조 근거: 2025_사업계획서.md 3번째 단락]**과 같이 명확한 출처 링크를 제공하므로 작가가 직접 원문을 대조·확인할 수 있습니다.
