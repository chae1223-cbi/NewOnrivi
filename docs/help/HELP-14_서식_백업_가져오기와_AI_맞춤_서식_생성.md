# 서식 가져오기·백업과 AI 서식 생성

## 이 도움말에서 해 볼 일

**서식 백업하고 가져오기** — 보관할 사용자 서식을 선택합니다.

### 따라 하기

1. 서식 관리에서 해당 서식의 파일 내보내기 또는 JSON 복사 기능을 사용합니다.
2. 백업 파일이나 텍스트를 안전한 위치에 보관합니다.
3. 가져오기 기능으로 테스트한 뒤 서식 목록에 나타나는지 확인합니다.
4. AI 생성 서식은 적용 전에 미리보기에서 글꼴과 여백을 확인합니다.

### 완료 확인

백업한 서식을 다시 가져와 목록에서 선택할 수 있습니다.

### 잘 안 될 때

가져오기가 실패하면 파일 형식과 JSON 내용이 온전한지 확인합니다.

---

## 기능 자세히 알아보기

## 1. 서식 백업(Export)과 가져오기(Import)

- **서식 백업 (JSON 파일로 내보내기)**:
  - 서식 관리 센터에서 공유하거나 백업하고 싶은 서식 카드의 **[내보내기]** 아이콘을 클릭합니다.
  - 해당 서식의 글꼴, 색상, 마진, 캡션 규칙, 커스텀 CSS가 포함된 `.json` 파일이 내 컴퓨터에 다운로드됩니다.
- **서식 가져오기 (Import)**:
  - 새 컴퓨터나 다른 작업장에서 서식 관리 센터의 **[서식 가져오기]** 버튼을 누르고 저장해 둔 `.json` 파일을 선택합니다.
  - 시스템이 서식의 유효성을 검사한 뒤 즉시 서식 갤러리 목록에 등록해 주며 바로 사용하실 수 있습니다.

---

## 2. 자연어 프롬프트를 통한 AI 맞춤 서식 생성

CSS 문법을 전혀 모르는 작가라도 원하는 문서의 분위기나 스타일을 말로 설명하기만 하면 AI가 완벽한 출판 서식을 즉석에서 작성해 줍니다:

- **활용 예시 프롬프트**:
  - *"고급스러운 문학 계간지 느낌이 나는 세리프 서식으로 만들어줘. 본문은 KoPub바탕체로 하고 제목은 딥 버건디 와인색으로 지정해줘."*
  - *"IT 스타트업의 테크 블로그 스타일로 깔끔하고 현대적인 서식을 작성해줘. 소스코드 블록의 가독성을 높이고 헤드라인에 틸(Teal) 색상을 포인트로 줘."*
  - *"공공기관 제출용 학술 보고서 스타일로 16pt 큰 글씨와 십진 분류 자동 번호가 포함된 서식을 생성해줘."*
- **생성된 서식의 검토 및 저장**:
  - AI가 생성한 CSS 코드는 미리보기 창에서 실시간으로 렌더링 결과를 즉시 확인할 수 있으며, 마음에 들면 [저장]을 눌러 영구 커스텀 서식으로 등록할 수 있습니다.
