# 온리비 어서 도움말 — 새 목차와 첫 화면 원고

> 검토용 초안 · 2026-11-05. 현재 게시 중인 도움말은 변경하지 않았습니다. 이 원고는 첫 화면과 탐색 구조를 검토하기 위한 것입니다.

## 도움말 첫 화면 원고

# 무엇을 도와드릴까요?

온리비 어서에서 문서를 처음 만들거나, 작업 중 막힌 부분을 해결할 때 필요한 안내를 찾아보세요. 처음 사용한다면 **5분 시작하기**부터 따라 해 보세요. 이미 원고가 있다면 아래에서 하려는 작업을 선택하면 됩니다.

### 처음 사용하시나요?

**[5분 시작하기](./도움말_5분_시작하기_초안.md)**  
작업장을 열고, 첫 문서를 만들고, 저장한 뒤 PDF 출력 화면까지 확인합니다. 마크다운 문법을 몰라도 따라 할 수 있습니다.

**기존 문서를 여시나요?**  
파일 탐색기에서 문서를 선택하고, 수정 전에 저장 위치와 읽기 전용 상태를 확인하세요. 작업장 연결 방법은 [작업 환경 연결](../frontend/public/help/HELP-04_작업_환경_연결.md)에 있습니다.

## 전체 문서 지도

첫 화면은 자주 하는 작업만 보여주고, 아래 상세 문서 지도에서 모든 장을 찾을 수 있게 합니다. 기존 HELP 번호는 유지합니다.

## 상세 문서 편집 기준

기존 문서를 일괄 축약하지 않습니다. 각 장을 다음 순서로 다듬으면 필요한 깊이를 유지하면서도 따라 하기 쉬워집니다.

1. **언제 쓰나요?** 실제 사용자 작업 한 가지를 첫 문단에 제시합니다.
2. **시작하기 전에** 필요한 폴더·파일·설정·권한을 적습니다.
3. **따라 하기** 메뉴 경로와 버튼 이름을 번호로 적고, 각 단계 뒤에 화면에서 확인할 결과를 넣습니다.
4. **예시** 짧은 원고나 상황을 제시합니다. 마크다운 설명에는 입력 예시와 표시 결과를 함께 둡니다.
5. **잘 안 될 때** 증상 → 확인 항목 → 다음 행동 순서로 적습니다.
6. **관련 도움말** 다음 작업에 필요한 1~3개 문서로 연결합니다.

## 게시 전 확인할 내용

- 현재 문서에는 과거 UI 명칭과 메뉴 경로가 섞여 있습니다. 특히 인쇄/PDF는 현재 **파일 → 내보내기**에서 통합 출력 창을 여는 흐름으로 맞춰야 합니다.
- 요금제, 지원 형식, AI 모델명처럼 변하기 쉬운 설명은 실제 제품과 대조합니다. 오래된 모델명을 첫 화면에 반복하지 않습니다.
- 웹과 데스크톱의 폴더 선택·저장 차이, 읽기 전용 상태를 실제 화면에서 확인합니다.
- 목차 링크와 이미지 경로는 게시 위치에 맞춰 조정합니다. 이 검토용 파일의 상대경로를 그대로 공개 도움말에 복사하지 않습니다.
